# R07 修改备注和标签

> 来源：docs/需求.md 第 3 节「典型流程」第 6 步、第 4 节「REQ-07 修改」、第 7 节 `githubUser.update`

## 背景与目标

管理员给保存的用户加备注、打标签，方便分类管理。只有这两个后台字段可以修改，来自 GitHub 的字段只能通过同步（R08）更新，保证和 GitHub 一致。

## 用户故事

- 作为管理员，我希望给保存的用户加备注、打标签，以便分类管理和日后查找。

## 验收标准

- [ ] R07-AC1：在详情页或列表行修改备注和标签后保存，提示「已保存」，刷新页面数据仍在。
- [ ] R07-AC2：备注超过 500 字、标签超过 10 个或单个标签超过 20 字时，前端直接提示；直接调用接口返回 `BAD_REQUEST`。
- [ ] R07-AC3：接口输入只接受 `id`、`remark`、`tags`，带上其他字段（如 `name`、`followers`）返回 `BAD_REQUEST`，GitHub 字段无法通过修改接口改动。
- [ ] R07-AC4：标签自动去掉首尾空格、去掉空标签并去重；备注去掉首尾空格，为空时保存为空（`null`）。
- [ ] R07-AC5：界面上 GitHub 字段只读，没有可编辑的入口。
- [ ] R07-AC6：修改不存在的记录返回 `NOT_FOUND`，前端提示「记录不存在」；修改后列表、详情、标签选项同步刷新。

## 不在范围内

- 修改 GitHub 字段（PRD 明确不允许）
- 批量打标签

## 依赖

- 依赖 R05 名单列表（列表行入口）
- 依赖 R06 用户详情（详情页入口）
