# R10 批量删除（P1）

> 来源：docs/需求.md 第 4 节「REQ-10 批量删除（P1）」、第 7 节 `githubUser.deleteMany`、第 9 节决策 D2

## 背景与目标

名单变长后，逐条删除效率低。列表支持勾选多条记录后一次删除，同样是物理删除。P1，本期尽量做。

## 用户故事

- 作为管理员，我希望勾选多条记录后一次删除，以便快速清理名单。

## 验收标准

- [✅] R10-AC1：勾选 N 条记录后批量删除，N 条记录全部从列表和数据库中消失，提示「已删除 N 条」（N 取接口返回的实际删除数量）。
- [✅] R10-AC2：列表每行有勾选框，表头有「全选本页」勾选框；有勾选时显示「批量删除（N）」按钮，没有勾选时不显示或禁用。
- [✅] R10-AC3：批量删除前弹出确认框，显示要删除的数量，并提示「删除后无法恢复，备注和标签会一起删除」；取消不发请求。
- [✅] R10-AC4：接口一次最多 100 个 ID，空数组或超过 100 个返回 `BAD_REQUEST`；其中已经不存在的 ID 忽略，返回实际删除的数量 `{ count }`。
- [✅] R10-AC5：删除完成后清空勾选并刷新列表；翻页、修改筛选条件时清空勾选。

## 不在范围内

- 跨页全选、按筛选条件全部删除

## 依赖
