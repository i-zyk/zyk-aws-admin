# R06 用户详情

> 来源：docs/需求.md 第 4 节「REQ-06 用户详情」、第 5 节（`createdById` 说明）、第 6.4 节（`/github-users/[id]`）、第 7 节 `githubUser.byId`

## 背景与目标

管理员在 `/github-users/{id}` 查看某条已保存记录的完整 GitHub 资料，以及备注、标签、添加人、添加时间、最后同步时间等后台信息。详情页也是修改、同步、删除（R07～R09）的入口。

## 用户故事

- 作为管理员，我希望看到某个用户保存下来的完整资料和后台信息，以便了解这条记录的来龙去脉。

## 验收标准

- [✅] R06-AC1：访问 `/github-users/{id}` 能看到 R03 中列出的全部 GitHub 资料（复用同一张资料卡片）。
- [✅] R06-AC2：另外展示后台字段：备注、标签、添加人、添加时间、最后同步时间。
- [✅] R06-AC3：添加人显示该用户的名字；添加人账号已经不存在时显示「已删除的用户」。
- [✅] R06-AC4：访问不存在的 ID，显示「记录不存在」页面（含返回列表的链接）；ID 不是正整数时同样显示「记录不存在」，不发请求。
- [✅] R06-AC5：页面处理加载中、出错状态；GitHub 不可用不影响详情页。
- [✅] R06-AC6：名单列表中的「查看」、资料预览中的「查看」都能进入详情页。

## 不在范围内

- 编辑、同步、删除按钮的行为（R07～R09）

## 依赖

- 依赖 R03 查看 GitHub 用户资料（资料卡片组件）
- 依赖 R05 名单列表（入口）
