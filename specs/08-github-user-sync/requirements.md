# R08 从 GitHub 同步

> 来源：docs/需求.md 第 4 节「REQ-08 从 GitHub 同步」、第 6.3 节「GitHub 调用规则」、第 7 节 `githubUser.sync`

## 背景与目标

保存的资料会过时。管理员可以手动把某条记录刷新成 GitHub 上的最新数据；按 GitHub 数字 ID 拉取，所以对方改名后也能同步到。

## 用户故事

- 作为管理员，我希望把某个用户的资料刷新成 GitHub 上的最新数据，以便名单信息保持准确。

## 验收标准

- [ ] R08-AC1：列表行和详情页都有「同步」按钮；同步成功提示「已同步」，资料和 GitHub 当前数据一致，「最后同步时间」更新。
- [ ] R08-AC2：同步只覆盖 GitHub 字段，备注和标签没有变化。
- [ ] R08-AC3：对方改名后，同步能拿到新的用户名（按 `githubId` 调用 `GET /user/{id}`）。
- [ ] R08-AC4：GitHub 账号已注销（返回 404）时，提示「该账号在 GitHub 上已不存在」，本地记录保留不变。
- [ ] R08-AC5：GitHub 限流或不可用时，分别提示「GitHub 请求过于频繁，请在 HH:mm 之后重试」和「GitHub 暂时无法访问，请稍后重试」，本地记录不变。
- [ ] R08-AC6：同步不走缓存；同步不存在的本地记录返回 `NOT_FOUND`，提示「记录不存在」；同步进行中按钮禁用。

## 不在范围内

- 定时自动同步、批量同步（PRD 2.2）
